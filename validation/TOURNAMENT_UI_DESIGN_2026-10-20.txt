TOURNAMENT UI DESIGN / 2026-10-20

USER REQUEST
Create the UI design for the existing LAN tournament. Implemented in the actual
game, with a separate interactive preview explicitly labelled as fictional data.
No backend rules, combat values, arena/table/character art or Hoenhorst changed.

DESIGN
Dark broadcast panel, warm paper/gold palette, Impact headings and system fonts.
Code block and copy action; three-stage lobby/tournament/champion navigation.
Connected roster cards with initials, own-player marking and host/offline labels.
Main roster/bracket plus separate personal status/action sidebar; collapsible
rules and participant/round information. Closed events do not advertise open entry.
Bracket rounds align vertically through span-based grid tracks; native CSS lines
connect paired winners. Own matches and winners stand out. 'Mein Weg' locates the
current personal path. Scroll positions survive updates; returning from a match
restores the outer panel to its top. Champion gets a distinct name/medal banner.
Responsive layout, semantic buttons, current-step ARIA and reduced-motion scroll.
Global gameplay keyboard shortcuts now yield to UI controls outside gameplay:
Space can activate Copy/Rules rather than sending an irrelevant brace command.
Escape still closes Help/Admin before the gameplay shortcut guard.
