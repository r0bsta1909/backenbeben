it did not establish visual quality of all combinations. Added native raster
regression tests check all six heads at0/25/50/75/100percent closure. Actual
white-eye pixels must disappear at closure, with brows retaining>=80percent

the first endpoint correction. Midpoint correctives fix that failure; the
threshold was not relaxed. A misplaced midpoint-construction block first
failed a Blender build and was corrected. One overlapping import locked the
GLB export; the final build waited for Blender success before importing.
An early oral-weight layer was third rather than second after joining gum
meshes. It was corrected and the source validator now checks the second UV
layer name and its full upper/lower ownership range.
